# Structural Reproducibility Dataset

This folder contains representative docking structures and pharmacophore overlays used in the manuscript.

All structures correspond to top-ranked Glide XP poses rescored with GNINA (CNN1) and are consistent with the manuscript-reported values.

Protein targets:
- hERG (PDB: 5VA1)
- DNA gyrase (PDB: 2XCT)
- MAPK14 (PDB: 3HVC)
- NLRP3 (PDB: 6NPY)

Prepared using:
- Schrödinger Maestro 2025-1
- Glide XP
- GNINA 1.3
- OPLS4 force field

# FLQ_Mod_2 Computational Datasets

This folder contains replicate-resolved computational datasets used in the manuscript:

"AI-guided cardiotoxicity-aware redesign of fluoroquinolones"

Files include:
- MM/PBSA free energy calculations
- Docking replicate scores
- RMSD trajectories
- RMSF analyses
- Interaction occupancy analyses

- ## Public Dataset Availability

All replicate-resolved docking, MM/PBSA, RMSD, RMSF, and interaction occupancy datasets used in this study are publicly available in the `/datasets` directory of this repository.

Representative structures correspond to centroid conformations
derived from the equilibrated final 100 ns segment of three
independent 200 ns MD simulations performed using Desmond
(Schrödinger Suite 2025-1).

Trajectories were exported from the equilibrated production phase
(100–200 ns) using 100 ps frame intervals.

All MM/PBSA analyses reported in the manuscript were calculated
from the equilibrated final 100 ns trajectory window.

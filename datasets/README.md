# FLQ_Mod_2 Computational Datasets

This folder contains replicate-resolved computational datasets used in the manuscript:

"AI-guided cardiotoxicity-aware redesign of fluoroquinolones"

Files include:
- MM/PBSA free energy calculations
- Docking replicate scores
- RMSD trajectories
- RMSF analyses
- Interaction occupancy analyses

- ## Public Dataset Availability

All replicate-resolved docking, MM/PBSA, RMSD, RMSF, and interaction occupancy datasets used in this study are publicly available in the `/datasets` directory of this repository.
